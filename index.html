04 / ABOUT THE DEVELOPER

关于我

H
P.

我目前就读于中国石油大学（华东）软件工程专业。相比只把引擎当作内容制作工具，我更希望理解画面背后的技术机制：顶点如何经过渲染管线，Shader 如何影响材质表现，光照如何塑造空间，以及 GPU 如何高效地完成这些计算。

我的学习路径以C++、计算机图形学与 OpenGL为基础，并逐步向 GLSL / HLSL、DirectX、Unreal Engine 与 Unity 延伸。我有 Unreal Engine 项目制作经历，也在持续积累场景制作、基础建模、材质和灯光方面的能力，希望把工程思维与视觉判断结合起来。

长期希望成长为兼具图形编程能力、渲染技术理解和美术沟通能力的 Graphics / Rendering TA。对我而言，好的作品不只是效果截图，还应该能解释技术原理、展示实现过程，并通过代码或 Demo 证明它确实能够运行。
